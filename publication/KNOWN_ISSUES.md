# Известные недостатки и границы проверки

- Художественное качество Бастиона ещё не утверждено пользователем. Технический PASS не означает качество Clash Royale.
- Текущие варианты используют общий язык брони и материалов; степень различия дизайнов требует художественной оценки.
- Анимации созданы программно. Убедительность веса, подготовки, удара и восстановления оценивается по настоящим кадрам, а не только по наличию клипов.
- SwiftShader в живом тесте даёт низкую частоту кадров (в предыдущей проверке около 3 FPS). Это не замер производительности на смартфоне.
- battle.mp4, walk-attack.mp4 и all-animations.mp4 — покадровый WebGL-рендер настоящей опубликованной сцены с фиксированным шагом симуляции. live-battle.mp4 — отдельная живая запись. Покадровая запись не подтверждает аппаратный FPS.
- Мобильный viewport проверен в Chromium, физический iPhone и Safari отдельно не проверены.
- Противник имеет отдельный визуальный облик, но параметры существующего тестового дуэлянта сохранены; новая боевая логика не добавлена.
- Текущая HTTPS-сцена может обновляться. Историческое доказательство — файлы конкретного Release, SHA256, run ID и commit SHA; параметр ?v= не гарантирует замороженный сайт.
- Основная игра не заменена. Изменения ограничены тестовой сценой и QA-инфраструктурой.

Автоматические ошибки конкретного запуска находятся в report.json / webgl-report.json соответствующего Release. Старые отчёты не заменяются новыми.
